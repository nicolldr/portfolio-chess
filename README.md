# Portfolio personal de ajedrez

Portfolio web interactivo inspirado en el ajedrez. El proyecto se desarrollará progresivamente, incorporando las tecnologías y funcionalidades a medida que avance el aprendizaje.

## Tecnologías previstas

- **Frontend:** React, TypeScript, HTML y CSS
- **Backend:** Java y Spring Boot para una API REST
- **Base de datos:** PostgreSQL

## Estructura del proyecto

- `frontend/`: aplicación web e interfaz de usuario.
- `backend/`: API REST y lógica del servidor.
- `database/`: scripts SQL y archivos relacionados con PostgreSQL.
- `docs/`: documentación técnica, diagramas de arquitectura y documentación del proyecto.
